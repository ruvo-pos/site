# Живые фото для ruvo.ac

Фото кладётся сюда под именем своего места — и после `node build.mjs` появляется на сайте. Пока фото нет, этого места на
сайте нет вовсе; в превью (`node build.mjs --preview`) пустое место видно — в полоску, с номером и тем, что снимать.
Подходят `.jpg`, `.webp` и `.png`, лучше не больше 2000 px по длинной стороне. Гости в кадре — с их согласия или без лиц.
Что снимать и подпись для незрячих — в `PHOTOS` в `src/content.mjs` (подпись поправить под то, что на фото).
